# Backend

Owner: thành viên 3 — Backend/API/Validation.

FastAPI điều phối pipeline và Pydantic validation. Models là nguồn export
schema dùng chung; thay đổi contract cần review từ frontend và extraction.
Tests ở `tests/` khi khởi tạo Phase 2. Không lưu tài liệu bằng database.
Chưa có server hoặc endpoint. Xem [kiến trúc](../docs/architecture.md).
