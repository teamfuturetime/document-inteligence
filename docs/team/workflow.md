# Quy trình phát triển hiện hành

[Quy trình GitHub của môn học](github-collaboration.md) hướng dẫn chia việc, nhận việc, issue/PR, review và Discussions. Phân công và kết luận phải có trên GitHub; không chỉ báo trong chat.

Nguồn duy nhất: [CONTRIBUTING](../../CONTRIBUTING.md). GitHub Flow: main runnable → nhánh ngắn → PR → Product checks → review → merge commit khi cần bảo toàn lịch sử nền. Không tự push/merge hoặc đổi settings nếu chưa được giao.

Kế hoạch [10 tuần 20/10](../planning/team-delivery-plan-2026-10-20.md) là lịch sử/đề xuất cũ, không tiếp tục quy ước 5 nhánh cá nhân dài hạn. Không tự gán handles/owners từ bản phân công đó. [Consolidation plan](../consolidation-plan.md) nêu xử lý PR #1/#2 và port các phần còn thiếu.
